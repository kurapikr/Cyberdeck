Build the base

1

Join the boards

Lay the 4 PCBs side by side to make one big board. Tie them together with wire through the holes.

💡Wrap the wire however you like. I tangled mine because I liked how it looked. Just make sure it's stable.
Photo: the 4 boards tied together
2

Attach the parts

Wrap wire through the holes to hold each part on the board:

  1. CYD
  2. ESP32
  3. OLED
  4. Charging module
  5. Battery

The ESP32 and the OLED get wired from the back of the board, so place them where the wires can pass through the holes.

// part 3

Software

Two screens, two separate programs. Do the setup once, then follow Part A for the CYD and Part B for the OLED.

Setup (do this once)

1

Install Arduino IDE

Download it free from arduino.cc/en/software and install it like any normal app. Open it once so it finishes setting up.

2

Teach it about your board

  1. Open Arduino IDE → Settings
  2. Find "Additional Boards Manager URLs" and paste this in:
https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
  1. Go to Tools → Board → Boards Manager, search esp32, install the one by Espressif Systems

Part A · Spotify screen (CYD)

Shows what's playing and lets you control it by touch.

I followed this tutorial for the Spotify part. This is my simple version of it.

Original tutorial ↗
1

Plug in and connect

  1. Plug the CYD into your computer
  2. Tools → Board → choose ESP32 Dev Module
  3. Tools → Port → choose the one that appears
  4. Tools → Upload Speed → set to 115200
💡No port showing up? Your cable is probably charge-only. Swap it for one that can sync a phone or transfer files.
2

Install the libraries

Go to Sketch → Include Library → Manage Libraries and install each of these by name:

TFT_eSPI
XPT2046_Touchscreen
ArduinoJson
TJpg_Decoder
WiFiManager

One library isn't in that search, so download it directly:

⬇ Download SpotifyArduino (.zip)

Then in Arduino: Sketch → Include Library → Add .ZIP Library → select the file you just downloaded.

3

Set up the display driver

Open this file on your computer:

Documents/Arduino/libraries/TFT_eSPI/User_Setup.h

Delete everything inside it and paste this in its place:

#define ILI9341_DRIVER

#define TFT_MISO 12
#define TFT_MOSI 13
#define TFT_SCLK 14
#define TFT_CS   15
#define TFT_DC   2
#define TFT_RST  -1

#define TOUCH_CS -1

#define LOAD_GLCD
#define LOAD_FONT2
#define LOAD_FONT4
#define LOAD_FONT6
#define LOAD_FONT7
#define LOAD_FONT8
#define LOAD_GFXFF
#define SMOOTH_FONT

#define SPI_FREQUENCY  40000000
#define SPI_READ_FREQUENCY  20000000
#define SPI_TOUCH_FREQUENCY  2500000

Save the file.

4

Create your Spotify app

  1. Go to developer.spotify.com/dashboard and log in
  2. Click Create app and name it anything
  3. For Redirect URI, type exactly:
http://127.0.0.1:8888/callback
  1. Check the Web API box, then Save
  2. Copy your Client ID, then click View client secret and copy the Client Secret too
5

Get your permanent login pass

Build this link (swap in your real Client ID), open it in a browser, and click Agree:

https://accounts.spotify.com/authorize?client_id=YOUR_CLIENT_ID&response_type=code&redirect_uri=http://127.0.0.1:8888/callback&scope=user-read-currently-playing%20user-read-playback-state%20user-modify-playback-state

The page will look "broken" after. That's expected. Copy everything after code= in the address bar.

Then in Terminal, run this (fill in your own values):

curl -X POST https://accounts.spotify.com/api/token \
-H "Content-Type: application/x-www-form-urlencoded" \
-d grant_type=authorization_code \
-d code=YOUR_CODE_HERE \
-d redirect_uri=http://127.0.0.1:8888/callback \
-d client_id=YOUR_CLIENT_ID \
-d client_secret=YOUR_CLIENT_SECRET

Copy the refresh_token from the response. That's your permanent pass.

⏰The code from the browser step expires in about 10 minutes, so do both parts of this step back to back.
6

Get the code and add your keys

Copy the full code from the tutorial and paste it into a new Arduino sketch.

Open the code ↗

Near the top, fill in your three values:

char clientId[] = "paste it here";
char clientSecret[] = "paste it here";
char refreshToken[] = "paste it here";
🔒Never upload your real keys to GitHub or share them. Keep them on your computer only.
7

Upload to the CYD

Click Upload. Watch the bottom panel for "Compiling" then "Writing."

💡Stuck on "Connecting..."? Hold the BOOT button on the board until it starts writing, then let go.
8

Connect it to WiFi

  1. On first boot, the CYD creates its own network called Spotify-CYD
  2. Connect your phone to it. A setup page should pop up
  3. Pick your home WiFi and type the password there
⚠️Use your 2.4GHz network. This board can't connect to 5GHz WiFi.
9

Play something

Start playing a song on Spotify. The screen shows what's playing. Tap to play, pause, skip, shuffle, change the volume, or open your playlists.

ℹ️The screen mirrors your playback. It doesn't play the audio itself.
Photo: the Spotify screen showing a song

If you get stuck

Upload fails or hangs
Try a different data cable, or hold BOOT while it connects
Touch feels backwards
Swap the min/max touch calibration numbers to flip that axis
Nothing shows when playing music
Make sure Spotify is actively playing somewhere
"SpotifyArduino.h not found"
Add it with the ZIP download, not the Library Manager search

Part B · Animated OLED (ESP32)

Plays any image, GIF, or video you choose.

A free website turns your media into code. You copy it and upload it.

oledanimationmaker.com ↗
1

Add your media

  1. Open oledanimationmaker.com
  2. Import the image, GIF, or video you want to show
  3. Check the preview
Screenshot: the website with your animation loaded
2

Copy the code

When you like the preview, copy the code the website gives you.

3

Plug in and connect

  1. Plug the ESP32 into your computer
  2. Open a new sketch in Arduino and paste the code
  3. Tools → Board → choose ESP32 Dev Module
  4. Tools → Port → choose the one that appears
ℹ️No extra libraries needed for this one.
4

Upload to the ESP32

Click Upload. Watch the bottom panel for "Compiling" then "Writing."

💡Stuck on "Connecting..."? Hold the BOOT button on the board until it starts writing, then let go.
5

Watch it play

Your animation should start looping on the OLED.

💡Blank screen? Check that SDA is on GPIO 21, SCL is on GPIO 22, and VCC and GND are on the right pins.
Photo: the OLED playing the animation
// part 4

Final touches

Almost there.

1

Test everything

Turn it on with the battery. Check that the Spotify screen connects and the OLED animation plays. Make sure all the wiring is stable.

2

Add foam tape

Once everything works, stick foam tape on the back of the board. This keeps it stable and comfortable to carry.

Photo: the back of the board with foam tape
3

Add a stand

Place it on a phone stand to display it on your desk. You can buy one or 3D print one.
